# 鲸屿 · DSH 微信插件

在微信上和鲸屿聊天，也可以交代她在 Mac 上做事。同一个微信私聊里的聊天和任务共用一个 DeepSeek Harness（DSH）原生会话。

## 安装和绑定微信

1. 打开 Mac 上的 DSH，点击侧栏的 **插件 → 添加插件**。把下载的 `dsh-jingyu-1.3.0.tgz` 的完整本机路径粘进去。可以在 Finder 里选中文件，按 **Option + Command + C** 复制完整路径。
2. 安装后点 **立即启用**，重启 DSH，再打开[鲸屿设置](http://127.0.0.1:18429)。这个页面只在运行插件的 Mac 上可访问。
3. 在鲸屿设置里点 **连接微信**。用准备和鲸屿私聊、派发工作的那个手机微信账号扫码并确认。然后在手机新出现的微信 ClawBot 对话发出网页显示的绑定代码，例如 `/claim 123456`。
4. 给鲸屿发一句「你好」。收到回复后，可以在 DSH 找到鲸屿的微信私聊会话。

已用 DSH `0.2.2-rc.3` 的 macOS 运行时验证原生会话创建与恢复。DSH 使用你在应用中已经配置的模型。安装包无需另装 Node.js，也无需给鲸屿填模型 API 密钥。

## 微信上交代工作

1. 在鲸屿设置中填入一个项目文件夹，开启 **远程工作**。用 **测试任务** 试一次，再到 DSH 的鲸屿微信会话按需要设置权限。
2. 在同一个微信私聊里直接发「帮我搜索最近的热点短剧」或「帮我检查这个项目为什么启动失败」。也可以随时接着聊天。
3. 任务结束后，鲸屿会把回复发回微信。很长的结果会附上 Markdown 报告。用「任务结果」可再次取回最近一项任务的结果。要取工作目录里的文件，可以发 `/file 报告.pdf`。

Mac 锁屏期间，DSH 和鲸屿需保持运行，电脑需保持唤醒并联网。接着电源时，可以在设置里打开 **通电时保持唤醒**。如果 DSH 暂停等待审批或补充信息，微信会收到提醒，去 Mac 上的 DSH 会话处理后任务可以继续。

## 设置鲸屿

- **人设**可以编辑名字、别名、她对你的称呼、性格和背景。在 Mac App 里点击「应用预设」后，新人设从下一轮开始使用。
- **记忆**可以直接编辑私聊记忆和群聊可用记忆。群里也会用到共用的人格和背景，适合在这些字段填可以公开的设定。
- **表情包**可以从 Mac 上传图片、设置名称、标签和描述。开启自动表情后，鲸屿根据聊天内容决定何时发送合适的图片。
- **语音**支持 Mac 系统音色，也可以在[独立设置 App](mac-app/README.md)里填写语音 API、自选模型和音色。对鲸屿说「用语音回复我」可单次请求。选择「每条回复都发音频」时，聊天和任务结果都带音频附件。微信传入的文字以及微信已经转写出来的语音可进入会话。
- **日记**可以按设定时间每天写一篇，也可以手动生成。内容取自当天启用后记录的私聊陪伴对话，可以在设置里查看，或在私聊发 `/diary` 阅读最近一篇。

微信私聊按照请求使用 DSH 权限并共享上下文。群聊和日记仍有自己的会话。

## 群聊

手机微信扫码开通的 ClawBot 通道是私聊。已能通过 AstrBot 收发群消息的机器人可加装[鲸屿群聊插件](integrations/astrbot/README.md)。配置允许的群后，群成员明确 @ 该机器人时，消息会进入对应的 DSH 群聊会话。你注册的普通微信小号仍需要一个实际能收发目标群消息的接入渠道。

## 开发

`npm test` 运行本地测试。使用 `npm pack --ignore-scripts` 生成安装包。插件的配置、微信凭据和回传队列存放在本机 `~/.dsh/jingyu/`，原生消息由 DSH 保存。

实现参考了 [WeChatAgent](https://github.com/sourcepro5/WeChatAgent) 的 DSH 工作流和[鲸鲸](https://github.com/Banan1cee/whale_girl) 的角色设置。微信私聊使用 [腾讯微信 ClawBot 通讯协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)。内置二维码编码器遵循其 [MIT 许可](src/vendor/QRCode/LICENSE)。
