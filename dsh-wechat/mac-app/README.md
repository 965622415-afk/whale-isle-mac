# 鲸屿 macOS 设置 App

独立的「鲸屿」应用保留旧版的深色侧栏、总览卡片、角色设定和提示词与预设页面。它通过本机地址操作 DSH 中的鲸屿插件。关闭设置 App 后，DSH 中的微信连接和任务继续运行。

## 使用

1. 在 DSH 启用鲸屿插件 1.2.0 或更新版本。
2. 把「鲸屿.app」放进「应用程序」，从 Finder 或聚焦搜索打开。
3. 到「微信桥接」查看连接状态，到「Harness 任务」选择项目文件夹并开启远程工作。

首次连上支持迁移的插件时，如果 Mac 上有旧版鲸屿资料，当前角色、模块提示词、人设预设和本机图包会自动导入。现有新版设置优先。可以在「诊断与关于」查看结果或重试。应用保留旧数据目录，DSH 继续使用自己的模型设置和微信绑定。

微信桥接当前接收微信 ClawBot 会话中的消息。注册的普通微信账号好友私信是另一条通道。

「语音发送」可选择 Mac 系统音色、BreezeBlue、MiniMax、硅基流动或自定义 OpenAI 兼容 API。可以填写音色 ID 和模型 ID，先试听再保存。在线合成会将待朗读文字发给所选服务。

「表情包」可以管理图片、标签和描述。开启「由鲸屿决定何时发表情」后，她会按对话内容自行挑选。普通文字回复仍可单独发送。

## 构建

在 macOS 上进入 `mac-app` 目录后运行以下命令。需要 Apple Command Line Tools，无第三方运行时依赖。

```sh
sh build-macos.sh /绝对路径/输出目录
```

构建产物为「鲸屿.app」，使用本地临时签名。当前验证环境为 Apple Silicon Mac。源码沿用仓库的 AGPL-3.0 许可证。
