# 鲸屿 4.3.0 · Mac 工作台验收

这是原版管理功能迁移的验收构建。微信执行端和 DSH 尚未接入，因此目前不能声称完整复制了原版所有端到端行为。

## 人设与完整提示词

1. 打开「提示词与预设」，应有七份「原版」预设：标准版、白璃、宅女鲸鲸、大肥鱼、有性子版、贴吧老油子、火力全开。
2. 点击「查看七份原始人设与完整原文」：检查来源路径、SHA-256 和完整 JSON，customPrompt 保持原文。
3. 使用任一预设，「角色设定」中的性格和背景应有内容；外观只提取原文明确提到的信息。原文没有职业时留空，不凭空编造。
4. 「表达风格」还应包含原版 preset/text/emotions 转换出的旧版表达规则。它们与完整 customPrompt 一起生效，不是只导入一段正文。
5. 点击「预览生效提示词」：应包含所选人设、原版内核规则以及当前场景的规则。私聊/群聊专属内容分别生效。
6. 可重新导入原版预设，或导入鲸屿 JSON、原版人设 JSON、原版插件市场的人设 ZIP。重新导入不会切换当前角色。

结构化字段是从原文整理的编辑摘要，原始 JSON 可独立核对。升级补空白字段，不覆盖用户已经修改的性格或提示词。

## 建议验收顺序

1. 切换一份原版人设，检查性格、背景及生效提示词。
2. 打开表情包总开关，导入原版图库，再导入一张本机 PNG/GIF。
3. 语音厂商选择「macOS 系统语音」，读取音色列表，保存后合成试听。三家在线厂商需要自己的 API Key；本次自动化使用本机 fixture 验证协议，未验证你的真实账户余额与权限。
4. 在「主动与提醒」创建一分钟后的 `local` 提醒；应用保持运行，电脑保持唤醒，系统需允许通知。
5. 进行一次真实模型私聊，再到「日记」生成当天日记。无模型密钥时不要把演示回复当作模型连接成功。
6. 插件市场先刷新目录。安装任意 ZIP 后应停用；JavaScript 插件需总开关和逐插件原生授权。只启用你信任的代码。
7. 退出后重新打开，检查人设、图库、语音配置、提醒与草稿持久化。

## 验证口径

单元测试验证原文、升级保护、密钥隔离、字段校验、真实图片导入、分类、提醒状态、语音接口和 ZIP 拒绝行为。Electron 冒烟使用独立数据、本机 HTTP fixture，验证模型请求、SSE、八个新增页、插件子进程、语音协议和日记落盘。它不等于已验证外部服务真实账户或微信收发。
